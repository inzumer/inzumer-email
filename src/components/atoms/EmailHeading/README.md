# EmailHeading

Email title (`h1`) or section title (`h2`), in the theme's heading font.

## Usage

```tsx
import { EmailHeading } from '@inzumer/email';

<EmailHeading>Welcome!</EmailHeading>;
<EmailHeading level={2}>What is saved</EmailHeading>;
```

## Props

- `level` — `1` (default) or `2`
- `children` — the text
